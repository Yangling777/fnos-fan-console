运行模式

  • 默认模式 — 使用内置保守温控曲线，安装后默认选择此模式，最安全。低温安静、高温积极散热。
  • 自动模式 — 根据自定义温控曲线自动调节转速。温度越高转速越快，支持最多 10 个节点精细控制。
  • 手动模式 — 固定转速运行。通过滑块设置 PWM 百分比，适合调试或特殊场景。
  • 全速模式 — 风扇 100% 全速运转。用于紧急散热，噪音较大。

温控曲线

  • 在自动模式下生效。每个节点定义一个"温度→转速"映射，节点之间线性插值平滑过渡。
  • 自动生成：选择节点数和温度范围，系统自动计算合理的转速分布（低温平缓、高温陡峭）。
  • 手动微调：直接修改节点的温度和转速值，曲线图实时预览。
  • 橙色虚线表示当前温度位置(跟随所选温度来源)。

温度来源

  • CPU — 以处理器温度(Intel coretemp / AMD k10temp 等)为调速依据。
  • 硬盘 — 以所有硬盘(drivetemp)中的最高温度为依据,适合散热重点在硬盘仓的机器。
  • GPU — 以显卡温度(amdgpu / nvidia / i915 等,含 nvidia-smi 回退)为依据;未检测到传感器时该选项自动置灰。
  • 最高值 — 取所有可用传感器(CPU、硬盘、GPU)中的最高温度,任何一路偏热都会及时提高转速,最稳妥。
  • 可在首页“温度来源”卡片或“高级设置”中切换;曲线图上的橙色虚线跟随所选来源显示当前温度。

区域管理(多风扇)

  • 侧栏「区域管理」可为每个风扇区域绑定独立的 PWM 通道、温度来源、最低转速与温控曲线,适合机箱有多路风扇的机器;
  • 新增 / 编辑:勾选 PWM 通道(同一通道不可被多个区域占用)、选择来源、设置下限、调整 2–10 节点曲线;
  • 区域超过 1 个时,首页会自动切换为“每个区域一张状态卡”(含独立模式切换);单区域用户无需使用本页;
  • 最后一个区域不可删除;保存后立即生效,可在首页查看各区域的温度 / 转速 / PWM。

温度趋势与日志

  • 首页仪表盘下方为“温度趋势”小图:按轮询间隔采样,保留最近约 2 分钟(60 个点)的 CPU / GPU / 硬盘温度曲线;
  • 「运行日志」页进入后每 5 秒自动刷新,离开页面即停止;支持按 全部 / 信息 / 警告 / 错误 筛选;
  • 「导出」把当前日志保存为 .log 文本;「清空」清除应用内运行日志(不影响主机系统日志)。

通知与告警

  • 「高级设置 → 告警通知」可开启浏览器通知(需授权):出现全速保护 / 高温降级 / 恢复正常时按区域提醒;
  • 「告警 Webhook」填写一个 http(s) 地址(留空关闭),应用会以 JSON 形式 POST 告警事件(事件类型、区域、原因、时间),Bark / 钉钉可直接填 URL;
  • Webhook 发送失败只记入运行日志,不影响风扇控制。

备份与恢复

  • 「高级设置 → 配置备份」可将当前配置(曲线、来源、下限、区域等)导出为 JSON 文件;
  • 导入时先做格式校验并二次确认,成功后一键还原;运行模式与端口不在导入范围内(保持当前值);
  • 壁纸图片仅保存在本机浏览器(localStorage),不会上传服务器;清理浏览器数据会丢失,重新选择即可。

安全机制

  • 最低转速保护：风扇转速不会低于设定的最低值（绝对下限 10%），防止停转。
  • 异常降级：温度传感器连续读取失败时，自动全速保护，持续失败则降级到默认模式。
  • 应用停止或崩溃时，看门狗进程会在 5 秒内恢复安全状态。
  • 访问密码：安装时可设置密码保护 Web 界面，在飞牛应用设置中可修改或关闭。

手机端与添加到主屏

  • 手机浏览器访问本页面会自动切换为窄屏布局(底部导航 + 单列卡片);
  • 支持“添加到主屏”:iPhone 用 Safari「分享 → 添加到主屏幕」;安卓用 Chrome 菜单「添加到主屏幕」,打开后为独立窗口样式(PWA);
  • 局域网 HTTP 环境下,部分安卓机型仅生成快捷方式形态,不影响使用。

卸载与重装

  • 卸载后风扇自动恢复为系统原始温控，不影响硬件。
  • 如果重装时提示"检查用户组失败"，请以 root 身份执行清理脚本：
bash /tmp/cleanup-fan-console.sh
  • 清理脚本随应用安装自动释放到 /tmp 目录，卸载后仍可用。
  • 如果服务器重启过导致脚本丢失，可手动执行以下命令：
userdel fan-console 2>/dev/null
groupdel fan-console 2>/dev/null
for vol in $(ls -d /vol* 2>/dev/null); do
  for dir in @appconf @appdata @apphome @appmeta @apptemp @appcenter; do
    rm -rf "$vol/$dir/fan-console"
  done
done
rm -rf /var/apps/fan-console

  • 壁纸系统 — 4 套预设壁纸 + 自定义图片上传(自动压缩,浏览器本地存储)。

  • GPU 温度来源 — 支持 AMD / NVIDIA / Intel 显卡温度(amdgpu / nvidia / nouveau / i915 / nvidia-smi / thermal zone),可作为风扇调速依据。
  • 温度趋势与安全 — 首页温度趋势小图(最近约 2 分钟);温度读取失败保护按所选来源分别生效,避免误伤其他来源。
  • 多区域管理 — 多风扇时可为每个区域绑定独立的 PWM 通道、温度来源与温控曲线,首页自动显示各区域状态面板。
  • 告警通知 — 浏览器通知 + 告警 Webhook(Bark / 钉钉可直接填 URL):全速保护 / 高温降级 / 恢复正常时按区域提醒。
  • 日志与配置备份 — 运行日志 5s 自动刷新、级别筛选与导出;配置一键导出 / 导入(含二次确认)。
  • 手机与安装 — 手机端布局适配、底部导航、设备信息自动读取;支持“添加到主屏”(PWA 独立窗口)。
  • 公开发布 v1.0 — 带查询参数访问等修复、68 例单元测试与一键部署脚本,版本号统一为 v1.0。
